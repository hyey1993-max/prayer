# 확인할 것 (원칙 선언문 카드)

레퍼런스: 단색 배경 + 밑줄 제목 + 소제목/본문 + 하단 서명·날짜 형식의 "Principles" 게시물.

- [ ] **계정 핸들 `@trace.map`은 임시값이다.** 실제 인스타 아이디로 바꿔야 한다 (`series.json`의 `handle`).
- [ ] **날짜:** 서명은 뺐고 날짜만 영문(October 6th, 2026)으로 넣었다. 게시하는 날로 바꾸려면 `series.json`의 `date`를 고친다.
- [ ] **UX Principles (2장):** 에세이 「The Essence of Spatial Design」의 UX 원칙 6가지를 요약한 문장이다.
- [ ] **Walking Principles (1장):** Tracé Story Chapter 1을 요약한 문장이다.
- [ ] **Map Principles (1장) — 가장 확인이 필요하다.** 브리프의 서비스 설명(평점 대신 감도, 사람이 고른 장소, 좌표·시간·거리·한 문장, 검은 선 지도)을 원칙으로 옮겼다. 실제 제품에서 지킬 수 있는 약속인지 확인해주세요. 특히 "알고리즘이 고르지 않는다"는 공개 약속이 된다.
- [ ] **색:** 레퍼런스와 같은 전기 파랑(#1a1af0)이다. 브랜드 색을 따로 정하면 `series.json`의 `color`만 바꾸면 된다.
- [ ] **글꼴:** 제목은 좁은 세리프(Instrument Serif), 본문 영문은 타자기체(Courier Prime), 본문 한글은 송명(옛 활판·타자기 느낌). 비교용으로 흑백사진체·고운바탕 버전을 `font_compare/`에 남겼다. 바꾸려면 `series.json`의 `kr_font`만 고친다.
