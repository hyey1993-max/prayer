# 원칙 모션 (principles_motion.html, mp4/)

레퍼런스: 검은 배경에 점·선·사각형만으로 개념을 보여주는 미니멀 도식(Change Your Mindset, Not Everything Is a Priority, When You Try to Fit In).
시각 언어는 같은 저장소의 The Path 작품(밤 팔레트 #0d0d10, 흰 점과 선, 걸어간 길만 따뜻한 주황 #c98f66)을 이어받았다.

## 장면 (각 6~9초 반복, MP4는 2회 반복 · 1080×1350 · 30fps)

| # | 원칙 | 무엇이 움직이나 |
|---|---|---|
| 01 | 사람을 줄 세우지 않는다 | 자유롭게 떠돌던 점 12개가 1~12 순위로 줄 섰다가 다시 풀린다 |
| 02 | 나열 말고 응축한다 | 흩어진 사각형 16개가 꽉 찬 사각형 하나로 모인다 |
| 03 | 동선은 흐르게 둔다 | 고정된 모듈 사이를 점이 곡선으로 흐르며 주황 꼬리를 남긴다 |
| 04 | 퍼널 대신 시퀀스 | 왼쪽은 깔때기로 떨어지고, 오른쪽은 노드를 골라 걸으며 길이 남는다 |
| 05 | 문턱은 낮게 | 높은 벽 앞의 점은 튕겨 나오고, 낮은 턱 위의 점은 넘어간다 |
| 06 | 완성하지 말고 함께 짓는다 | 사방에서 온 점들이 빈 격자를 하나씩 채운다 |
| 07 | 목적지를 지운다 | 직선은 0번 멈추고 지나가고, 곡선은 4번 멈추며 고리를 남긴다 |
| 08 | 내면의 지도를 그린다 | 맴돌며 넓어지는 궤적이 남고 격자가 사라진다 |
| 09 | 나만의 북소리를 듣는다 | 같은 박자로 행진하는 줄 아래로 점 하나가 자기 박자로 걷는다 |
| 10 | 지금 이 순간을 기록한다 | '나중에' 격자를 훑다가 마지막 '지금'에 불이 들어온다 |
| 11 | 평점이 없다 | 별점 4.5가 흩어지고 "왜 이 장소인가"가 타이핑된다 |
| 12 | 알고리즘이 고르지 않는다 | 많이 저장된 점만 커지다가, 작은 점 하나가 선택된다 |
| 13 | 맥락을 남긴다 | 점 하나에 좌표·시간·거리·이유 라벨이 차례로 붙는다 (실제 값은 넣지 않았다) |
| 14 | 검은 선으로 그린다 | 점선 최단 경로 옆으로 실제로 걸은 흰 선이 그려진다 |

## 태극 인터랙션 (taegeuk_interactive.html, mp4/15_taegeuk_yin_yang.mp4)

레퍼런스: 회색 바탕 위 흰·검은 붓질이 감기는 태극 이미지.
흰 입자 6천 개 남짓, 검은 입자 6천 개 남짓이 태극 모양 자리로 돌아가려 하고, 흐름장이 흰색과 검은색을 반대 방향으로 감는다.

- **조작:** 캔버스를 끌면 그 자리에 소용돌이가 생긴다. 슬라이더(또는 ← →)로 응축↔역동을 바꾼다. 스페이스나 "흩트리기"는 바깥으로 흩는다.
- **자동 재생:** 18초에 응축 → 역동 → 응축으로 한 바퀴 돈다. 가운데쯤 보이지 않는 손이 S자 경계를 따라 젓는다.
- **문장 (에세이 원문 그대로):**
  - 응축 쪽: "이는 정제된 시스템 안으로 압축시켜 규칙을 만드는 일본의 ‘응축의 문화’와 닿아있다."
  - 가운데: "음과 양이 서로를 밀어내고 끌어당기며 끊임없이 순환하는 태극의 ‘역동성’처럼, 유저의 시선과 동선은 인터페이스 위를 유연하게 흘러가야 한다."
  - 역동 쪽: "이것은 문화사적으로 음과 양의 에너지가 태극처럼 끊임없이 충돌하는 역동성을 나타낸다."
  - 라벨("응축", "태극의 역동성", "음과 양")도 원문 단어에서 가져왔다.
- **MP4:** 자동 재생 18초, 1080×1350, 약 11MB. `node scripts/capture_taegeuk.js`로 다시 뽑는다 (시뮬레이션이 고정 스텝이라 매번 같은 결과).
- [ ] 릴스(9:16)용이 필요하면 캔버스 높이만 늘려 다시 뽑는다.
