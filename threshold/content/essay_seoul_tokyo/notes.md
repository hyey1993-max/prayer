# 확인할 것 (에세이 기반 콘텐츠)

- [ ] **서비스 이름:** 카드 상단과 마지막에 THE THRESHOLD로 넣었다. 에세이에서는 Tracé였다. 정해지는 대로 `cards.json`의 `brand`만 바꾸고 다시 렌더링하면 된다.
- [ ] **인스타 레퍼런스(unfold_by_igis):** 이 환경에서 인스타그램이 막혀 있어 보지 못했다. 카드 디자인은 내 판단으로 만든 검은 격자 + 세리프 스타일이다. 레퍼런스의 글자 크기, 색, 카드당 글자 수를 알려주거나 화면 캡처를 올려주면 맞춰서 다시 만들겠다.
- [ ] **스레드 중 혜원 님의 경험·입장으로 읽히는 문장:** S05 "제일 좋아하는 개념", S06 빌드 일기(뭘 뺄지 오래 고민), 연재 5/5 "낮은 문턱이 있는 쪽을 만들고 싶다". 실제와 다르면 고쳐주세요.
- [ ] **에세이 주장의 사실 여부:** 미쓰이·모리의 개발 방식, 서울 건축의 단기 분양 비중, 오모테나시 해석은 에세이의 견해로 썼다. 카드에는 "많다", "닮았다"처럼 단정을 피했다. 일반 대중에게는 논쟁이 될 수 있는 주제라 댓글 반응을 보고 수위를 조정하자.
- [ ] **순서:** 스레드(S01~S08) → 반응 좋은 문장으로 카드/릴스. 릴스 A가 THE THRESHOLD(문턱)와 가장 잘 이어져서 첫 릴스로 추천한다.
- [ ] 릴스 영상으로는 PNG를 장당 1.5~2초로 이어 붙여 직접 편집해야 한다. 이 환경에서는 영상 파일은 만들지 않았다.

## 연재 캐러셀 (series.json)

- [ ] **원문 그대로 수록:** 본문은 에세이 문장을 그대로 옮겼다. 큰 제목(pull)만 각 카드의 원문 구절을 줄여서 뽑은 것이다. 손댄 곳은 두 군데다: "일본의. 고도의" → "일본의 고도의", "수단이 된다.결국" → 문장 사이 띄어쓰기. "힐즈 처럼", "전체주의 적", "공존 한다" 같은 띄어쓰기는 원문대로 두었다.
- [ ] **1편 표지 제목:** "도쿄는 구역을 짓고, 서울은 건물을 판다"는 원문 1장을 요약한 내 문장이다. 원문에 없는 문장이 표지에 있어도 괜찮은지 확인해주세요.
- [ ] **구성:** 1편 = 원문 1장(도시 개발 방식) + 2장(문화사). 2편 = 3장(디지털)을 힌트 2개(야마모토 리켄, 데 카를로)와 적용점 6개로 나눴다. 적용점 번호와 이름(인간적 척도, 응축, 역동성, 시퀀스의 동선, 낮은 문턱의 내비게이션, 과정)은 내가 붙였다.
- [ ] 인스타 캐러셀 한도는 20장이다. 1편 14장, 2편 19장.
- [ ] 사진: 서울 사진 2장(한강 야경, 카페 창가)을 한국 부분과 마무리 카드에 썼다.
